# Match-level dataset provenance

Use this check after human box annotation and before training or reporting holdout accuracy. It guards against different frames from one match landing in both training and validation. It does not verify box geometry, label quality, permission to use footage, or detector accuracy.

Place `split_manifest.csv` at the dataset root with columns `image,split,source_match,source,rights`. Each row names one image using a forward-slash path such as `images/train/USWASAM1-Q3-000012000.jpg`. Put the matching YOLO box file at `labels/train/USWASAM1-Q3-000012000.txt`. Empty label files are allowed for reviewed negative frames. Use `train`, `val`, or `holdout` as the split. Give every frame from a match the **same** `source_match` (event plus match, for example `USWASAM1:Q3`), including adjacent and reencoded frames. Record the footage or dataset URL in `source` and the actual rights or permission basis in `rights`; a nonempty field is an audit trail, not a legal clearance decision.

Run `python -m control_vision.training.split_manifest datasets/biobuzz-v1`. The command rejects missing labels, unlisted split images, byte-identical cross-split images, and one `source_match` in more than one split. It prints image counts, match count, and a SHA-256 for the manifest. Keep the holdout event separate from model selection and tuning. The training utility's dataset validator also checks YOLO box coordinates and decodes images. Neither check can identify the same match recorded under inconsistent IDs or prove visual labels are correct; inspect the manifest and sampled boxes manually.

Two public older-season FTC robot datasets currently advertise CC BY 4.0: [FTC Robot Detection, 54 source images with `blue_robot`, `objects`, and `red_robot` classes](https://universe.roboflow.com/ftc-robot-detection/my-first-project-5aza1) and [testing, 84 images with a `robots` class](https://universe.roboflow.com/testing-yxqaj/ftc-robot-detection). Check the source images and attribution terms before any use. Their size and viewpoint do not establish BIOBUZZ fixed-camera accuracy. [CVAT's Ultralytics YOLO format guide](https://docs.cvat.ai/docs/dataset_management/formats/format-yolo-ultralytics/) describes matching image and label names for box export.
