# Match-level dataset provenance

Use this check after human box annotation and before training or reporting holdout accuracy. `train_yolo` runs it before every release training run and refuses to start without the manifest; only `--exploratory-without-manifest` skips it, and that model's record says `exploratory_unverified` (see `docs/TRAINING.md`). It guards against different frames from one match landing in both training and validation. It does not verify box geometry, label quality, permission to use footage, or detector accuracy.

Place `split_manifest.csv` at the dataset root with columns `image,split,source_match,source,rights`. Each row names one image using a forward-slash path such as `images/train/USWASAM1-Q3-000012000.jpg`. Put the matching YOLO box file at `labels/train/USWASAM1-Q3-000012000.txt`. Empty label files are allowed for reviewed negative frames. Use `train`, `val`, or `holdout` as the split. Give every frame from a match the **same** `source_match` in the form `EVENT:MATCH` (for example `USWASAM1:Q3`), including adjacent and reencoded frames. The text before the first `:` is the event and must not be blank, and neither may the match. Case, whitespace, and leading zeros in match numbers are ignored, so `USWASAM1 : q03` and `uswasam1:Q3` are the same match. Record the footage or dataset URL in `source` and the actual rights or permission basis in `rights`; a nonempty field is an audit trail, not a legal clearance decision.

Run `python -m control_vision.training.split_manifest datasets/biobuzz-v1`. A relative `--manifest` path is resolved against the dataset root, and the manifest must lie inside it. The command rejects missing labels, label files with no manifest row, images under `images/` that the manifest does not list (including folders other than `train`, `val`, and `holdout`), byte-identical cross-split images, and one match in more than one split. Train and val may share an event as long as no match crosses them. The holdout is defined by event: every event that has a holdout row must appear only in holdout, so no train or val frame may come from a holdout event such as STL North, even from a different match. The command prints image counts, match and event counts, the holdout events, and a SHA-256 for the manifest. Keep the holdout event separate from model selection and tuning. This check does not verify YOLO box coordinates or decode images. It cannot identify the same match recorded under different event codes or prove visual labels are correct; inspect the manifest and sampled boxes manually.

Two public older-season FTC robot datasets currently advertise CC BY 4.0: [FTC Robot Detection, 54 source images with `blue_robot`, `objects`, and `red_robot` classes](https://universe.roboflow.com/ftc-robot-detection/my-first-project-5aza1) and [testing, 84 images with a `robots` class](https://universe.roboflow.com/testing-yxqaj/ftc-robot-detection). Check the source images and attribution terms before any use. Their size and viewpoint do not establish BIOBUZZ fixed-camera accuracy. [CVAT's Ultralytics YOLO format guide](https://docs.cvat.ai/docs/dataset_management/formats/format-yolo-ultralytics/) describes matching image and label names for box export.
